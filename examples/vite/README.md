# Bonkei in a Vite app

The smallest host: `bonkei`, React, React DOM and three, a default Vite config.

    npm install
    npm run dev

CI installs the packed `bonkei` tarball into a clean copy of this folder (`scripts/smoke/vite.mjs`), and every PR gets this folder as a StackBlitz template on the PR's build (pkg.pr.new).
