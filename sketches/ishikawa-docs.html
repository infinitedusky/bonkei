Ishikawa (fishbone)

For root-cause write-ups: the effect at the head, the main kinds of cause as bones, the causes along each bone. The same text Mermaid reads.

FlatIso3DFit
Live diagram, drawn by Bonkei from the fence below. Flat / Iso / 3D switch the view.

Syntax

LineWhat it is
ishikawa-betaThe first line. ishikawa works too.
The next lineThe effect: the problem, drawn at the head.
Lines at the effect's indentCategories: one bone each, above and below the spine in turn.
Lines indented under a categoryCauses, along its bone. Indent again for causes of a cause (as deep as you like).
%% …A comment, ignored.

When a line can't be read

Bonkei draws the rest and warns with the line number, the same as for flowcharts. A tab in the indentation, or a line indented less than the effect, is skipped. See Errors and warnings.

How it differs from Mermaid

Same text, same structure. Bonkei draws it in its own style and themes, and adds iso and 3D.
