Function · from bonkei

render()

Mount a diagram into any DOM element without touching React; returns a handle.

function render(el: HTMLElement, source: string | GraphInput, options?: BonkeiOptions): BonkeiHandle

Parameters

NameTypeDescription
elHTMLElementThe element to draw in. The diagram fills it.
sourcestring | GraphInputMermaid text, or a graph built by hand.
optionsBonkeiOptionsDiagram options and callbacks. Options here win over the diagram's frontmatter.

Returns

BonkeiHandle: update(source), setMode(mode), destroy().

Example

import { render } from 'bonkei'

const handle = render(document.getElementById('diagram'), `flowchart LR
  Build --> Test --> Ship`, { mode: 'flat', onError: e => console.warn(e.message) })
